# Changelog

## 1.0.0

- The `converter_studio` resource type (API key kept as a secret, API address).
- Six Bun scripts: convert a file from the workspace storage (S3) or an upload, convert a file from
  a URL, get a conversion, confirm a quoted conversion, list the formats, get the account's credits.
- Built on the `converter-studio` 1.0.0 client; tested on Windmill 1.882 with Bun 1.4.5.
